# My Crypto Smash ゲームデザイン

スマホを傾けて・振って・はじいて、ヒーローのマレット（丸いメダル）をフィールドで滑らせ、
エネミーにぶつけて倒し、GUM を稼いで入金口にノルマを納め、エンブレムで台とスキルを強化していくゲーム。縦持ち専用。

**遊びの本体はピンボール**（ユーザーの指定）。
**世界観**（ユーザーの指定）：主人公は古いゲームコーナーの部屋に閉じこめられ、呪われたピンボールで GUM を稼いで「入金口」にノルマを納めないとゲームオーバー。台を育ててノルマのインフレに打ち勝ち、脱出する。
このピンボールは昔はみんなに遊ばれていたが、だれにも遊ばれなくなって仕掛けがなくなり、古ぼけた台になった。**挑戦のはじめの台は打ち出しとフリッパーだけ**（ユーザーの指定）。台に宿るジョーカーも、コモンのピエロの姿まで退化している。プレイヤーが台の部品と大きな仕掛け（どちらも「ギミック」）をエンブレムで買い足して台を豪華にするほどピエロのレアリティが上がり、最後にジョーカーに戻る（下の「ギミックとピエロの成長」）。通貨は GUM（納品とリロール）と **エンブレム**（買い物）の 2 つ（下の「挑戦のサイクル」）。
画面と音は様式「呪われたカーニバル」で作り、**台が直る（ピエロの段階が上がる）ほど UI も音も直っていく**（下の「画面（UI）の様式」「音」）。
はじめての挑戦は、ピエロの案内つきのチュートリアル（ノルマ 0）から始まる（下の「チュートリアル」）。
ピラミッドはクリア後のエンドレスモード用のボーナスステージで、**本編では閉じている**（`save.endless` で開く）。開いているときは G・U・M の 3 つのレーンを点けると台のまん中に入口が開き、球が入ると 15 秒のピラミッドに突入、時間切れでピンボールにもどる。

## ラストステージ・エンディング・エンドレス（`src/game/final.ts`・`quota.ts`・画面は `src/ui/ending.ts`）
**終わり方は 2 つ**（ユーザーの指定）：ノルマ 10 を納めたとき、台に宿るピエロがジョーカーでなければ**通常のエンディング**、ジョーカーなら**ラストステージ → 真のエンディング**。
- **通常のエンディング**（`normalEnd`・`openNormalEnding`）：ジョーカーでないままノルマ 10 を納めると、部屋の扉が開いて出られる。ただし台は完成していないので、古ぼけた台はだれの話題にもならない。
  - Limited は選ばない（納品の QUOTA 10 CLEAR! のあと、すぐに場面へ）。短い場面：いまの姿のピエロが約束どおり扉を開ける → 夜の路地（店は暗いまま。だれも気にとめない）→ ピエロが「台を完成させれば……」とヒントを言う（`clown-lines.ts` の `NORMAL_END`。姿 0〜3 ごとに door・hint 各 3 つ）→ 記録（ESCAPED・NORMAL END：数字のます（NAME・PLAYS・BEST GUM など）と札（SKILL TREE・エンブレム・KEEP）。説明の段落は置かず、ヒントはピエロのセリフが言う。ピエロが上がる条件の数は出さない）。ボタンは「最初から挑む」。
  - そのあと**スキルツリーを持って最初からやり直す**（`clearChallenge`：GAME OVER と同じものを失うが、**使い残したエンブレムは持ちこせる**。エンドレスは開かない）。部屋を出た回数は `save.clears`、記録は `save.clearRecord`。見る前に閉じたら、次に開いたときに出す（`save.pendingNormal`）。
  - 前の版で「ジョーカーでなければノルマ 11・12…と延長」していたセーブは、開いたときに通常のエンディングへ移す。
- **ラストステージ**（ユーザーの指定：ジョーカーになったあとに始まる、それまでのボスが全部出てくるボスラッシュ。突破で脱出）。
  - 始まる条件：ノルマ 10 を納めたときに、ピエロがジョーカー（`finalReady`）。始まる前に、ジョーカーの口上の場面（`openFinalIntro`）。打ち出しを待つ台の液晶に「LAST STAGE」と出て、打ち出すとボスラッシュが始まる。
  - 中身：レイドボス 5 体（10・20・30・40・50 台目のボス。`FINAL_FLOORS`）が順に出る。的は出ない。ボスが出るたびに、そのボスの台の掟がかかる（10＝フリッパーが短い・20＝坂が急・30＝ライトが消える・40＝傾きが反対・50＝ボスが速い）。制限時間 90 秒（`FINAL_TIME`）。上の札は「BOSS n/5」。全部倒すと ESCAPE!!。
  - ボスの体力（`FINAL_HP` 55・71・88・108・126）× 攻撃力の比の平方根（`finalScale`：攻撃力（基本 × 色の威力の平均）÷ 6 の平方根。強くなるほど楽になるが一撃では終わらない）。周を重ねてジョーカーに届いた自動プレイ（下の「測り方」）で、1 回目の突破が 6〜7 割になるように測った値（自動プレイは 90 秒でボスに 200〜300 ほどしかダメージを与えないので、体力の数字は小さい）。
  - 挑めるのは 3 回まで（`FINAL_TRIES`。始めた時点で数える）。3 回とも失敗で GAME OVER。ラストステージのプレイもエンブレム +1、GUM の発表もある（GUM の単位はいちばん先の台）。突破したかどうかはプレイが終わった瞬間に決めてセーブする。エンディングを見る前に閉じたら、次に開いたときにエンディングを出す（`save.pendingEnding`）。
- **真のエンディング**（ユーザーの指定）：タップで送る場面。ジョーカーがプレイヤーを認めて扉を開ける → 台の過去を明かす（昔は町いちばんの人気者で子どもらが行列を作った → 新しい遊びが増えてだれも来なくなり、仕掛けは外され、ジョーカーはピエロまで落ちぶれた → 台を育ててくれる遊び手を待っていた）→ 豪華になった台のうわさが広がり、古いゲームコーナーはレトロゲームの名所としてにぎわう → 記録（ESCAPED!・TRUE END：プレイヤー名・かかったプレイ数・いちばん大きかった GUM。`save.escapeRecord`）。
- **エンドレス**（ユーザーの指定：真のエンディングのあとに解放）：脱出すると `save.endless = true`（ピラミッドの入口が開く）。ノルマは続きから 4 倍のまま終わりなく続き（札は「ENDLESS n」）、ラストステージも通常のエンディングも来ない。どこまで納めたかを `save.endlessBest` に記録する（ラボの図鑑に出る）。
  - 脱出したことがあれば、GAME OVER のあとに「本編を最初から」（10 ノルマとラストステージ）か「エンドレスを最初から」を選べる（`resetChallenge(save, endless)`）。

## ホーム画面（`src/ui/title.ts`・`title.css`）
- **開くたびに最初に出る**（ユーザーの指定）。暗いゲームコーナー：うしろに本物の台（canvas。打ち出しを待つ台がそのまま動いている）がまん中にぼんやり光り、まわりは闇。上から舞台の光が 2 本ゆっくり揺れる。上にロゴ（電球の枠・「MY CRYPTO」の血の帯・1 字ずつはずむ「SMASH」・のぞくピエロ。ピエロはいまの姿の絵）、下にチケットの形のメニュー。
- メニュー（2 語まで。説明の文は置かない）：
  - セーブがある（`save.name` がある）：**つづきから**（黄＝主ボタン。名前とノルマの札）・**はじめから**・**設定**・**チャット**
  - セーブが無い：**はじめる**（導入へ）・**設定**・**チャット**
  - チャットは共通基盤の SDK が読めたときだけ出る（`platformOn()`。SDK が遅れて読まれても、開いている間に出てくる）。押すと全体チャットの窓（`openChat()`。docs/PLATFORM.md）
- **つづきから**：チケットが下へ飛び、ロゴが上へ跳ね、闇が晴れて台へ（600ms）。はじめて台へ入ったときだけ、前に閉じたときの続き（`main.ts` の `resume`：見ていないエンディング・ヒートの部品選び・足りずに終わっていたときの GAME OVER）と、途中で閉じたプレイの GUM の知らせを出す。
- **はじめから**：2 回たしかめる（1 回目：消えるもの（名前・スキルツリー・図鑑・記録）の札と「消す」／2 回目：「本当に？」と「全部消す」）。セーブを全部消し（`?reset=1` と同じ消し方。`wipeSave`：読みこみ直すまで書かないので、閉じるときの書きこみで戻らない）、幕のワイプの裏で読みこみ直して、ホームを出さずに導入から。設定の「データを消す」も同じ流れ（2 回押す）。
- **設定**：設定のシートがホームの上に出る。
- **遊んでいる途中から戻る**：設定のシートの「ホームへ」。プレイ中なら時間が止まり（`world.step` を呼ばない）、「つづきから」でそのまま続く。
- ホームが出ている間は `<html class="titling">`：台（canvas）とホームと、上に重なるもの（設定のシート・モーダル・ワイプ）のほかは隠す。PC は 3 列の外まで覆う。ピエロのひとこと・打ち出しの手の絵・チュートリアルの案内は出さない。BGM は台の曲（idle）。
- 確かめ用の URL：`?go=1` でホームをとばす（名前がなければ導入、あれば台へ）。`?name=…` は導入をとばすだけで、ホームは出る（セーブがある扱い）。

## 導入とピエロのセリフ（`src/ui/intro.ts`・`src/ui/story.ts`・セリフは `src/game/clown-lines.ts`）
- **導入**（ユーザーの指定）：はじめて開いたときだけ（`save.name` が空のとき）。タップで送る短い場面の連なり（文字は 1 つずつ出て、触ると最後まで出る。もう一度触ると次へ。右上に「スキップ」）。
  1. 夜の道：路地の奥の古いゲームコーナー（ネオンの看板が明滅）から「……おーい……」と呼ぶ声
  2. 店の中：暗がりにコモンのピエロの絵が浮かび上がり「いらっしゃい、お客さん」
  3. ピエロが名前をたずねる → プレイヤー名を入力（10 文字まで。空なら「お客さん」。`cleanName`）
  4. 窓のない暗い部屋へ案内され、古いピンボール台がぼんやり光っている。**扉は見ている人の背後にある体裁**（ユーザーの指定）：扉そのものは描かず、背後から差しこむ光が床に四角く落ち（遠くほど細い）、奥の壁を照らし、その中に自分の影（人のシルエット）が台の方へ伸びている（`intro.ts` の `BEAM`。SVG）
     → 突然ドアが閉まる：**四角い光が右の端へ細くなって消える**ことで閉まったと分かる（はじめはゆっくり最後に勢いよく 0.5 秒。`story.ts` の `closeDoor`・`gapPoints`）。閉じきった瞬間に「バタン!!」・画面の揺れ・音・振動。部屋が一瞬まっくらになり、1 秒ほどして台の明かりがちらついて目を覚まし、闇の中にぼんやり浮かび上がる（`main.css` の `.sc-room.shut`）
  5. 闇のまま（ワイプでなく重ねて切りかえる：`Beat.soft`）台が赤く光り（CURSED）、ピエロが呪われた台と入金口を説明（3 プレイ以内にノルマを納めないと終わり。稼いで台を育てれば出してやる）
  6. ピンボールのページ（打ち出しとフリッパーだけの台）へ。ここからチュートリアル（下の節）
  - 絵は CSS とピエロの絵だけで描く（背景の画像は足さない）。セリフは骨の紙、ト書きは墨の札、話し手は血の札。場面が変わるときは斜めの帯のワイプ、閉じるときは紙めくり（口上・エンディングも同じ枠。`src/styles/show.css` の `.st-*`）。
- **プレイヤー名**（`save.name`）：GAME OVER でも残る。設定の「プレイヤー名」で変えられる。プレイヤー自身のセリフと性格はない。
- **ピエロの性格**（ユーザーの指定）：陽気にあおるが、台が育つほど本気で応援しはじめる。名前を入れたあとはプレイヤー名で呼ぶ。姿ごとの口調：コモン＝小ばかにする／アンコモン＝少し興味を持つ／レア＝助言しはじめる（倍率の並べ方など）／エピック＝本気で応援／ジョーカー＝相棒・誇り。台の過去はレア以降のセリフで少しずつにおわせ、エンディングで明かす。
- **セリフが出る場面**（各姿 × 各場面で 3 つ以上。`CLOWN_TABLE`。文字だけで声は付けない。プレイ中の英語の実況はいまのまま）：
  | 場面 | 出る所 |
  | --- | --- |
  | 打ち出しを待つ台 | 打ち出さずにいると、右上の実況のピエロの左に小さな吹き出しで 16〜24 秒ごとに（`title` の場面） |
  | プレイの前 | 打ち出しを待つ台を組んだとき、右上の実況のピエロの左に小さな吹き出しで 4.2 秒（台を覆わない）。残りプレイと「あと何 GUM」（`{left}`・`{rest}`）。最後の 1 プレイ・もう納められるときは別のセリフ（`preScene`） |
  | チュートリアル | 案内の吹き出し（`TUTORIAL_LINES`・`tutorialLine`。下の「チュートリアル」） |
  | 納品 | QUOTA n CLEAR! の下（触るか 3.4 秒で Limited へ） |
  | ギミックを買った・進化した | NEW GIMMICK! と進化の演出の下（進化は新しい姿でしゃべる） |
  | GAME OVER | GAME OVER の下 |
- 吹き出しは破れたチケットの形（骨の紙・墨の縁・紫のずらした影）にピエロの絵（`src/ui/talk.ts`・`src/styles/g3.css`）。文字は 1 つずつ出る。

## チュートリアル（ノルマ 0。判定は `src/game/quota.ts` の `tutorialState`・案内の画面は `src/ui/coach.ts`・つなぎは `main.ts` の `tutorialTick`）
ユーザーの指定：③三角のばね・④内側の通路・⑦丸いばねの 3 つを足してピンボールを強化していく流れを紹介する。1 プレイごとに 1 エンブレムもらえるので、練習のノルマ「50 GUM」を稼ぐために 3 回遊び、そのつどギミックを買って台に付ける。50 GUM を払って、ノルマの報酬のエンブレムと余った GUM を持った状態で、実質の最初のノルマ（ノルマ 1）が始まる。
- **挑戦のはじめはいつもノルマ 0**（納品額 `TUTORIAL_QUOTA` 50・3 プレイ・1 プレイごとにエンブレム +1。GAME OVER・通常のエンディング・エンドレスの最初からも 0 から）。GAME OVER にはならない：3 プレイ目のあとに 50 に届かなくても、手持ちを全部納めて足りない分はピエロのおまけ（`deliver` の `gift`。納品ボタンの額は手持ちの額、TUTORIAL CLEAR! の下に「おまけ n GUM」）。Limited は選ばない。納めると報酬のエンブレム（`TUTORIAL_REWARD`）を受け取り、余った GUM を持ってノルマ 1 へ。
- 札の表記は「TUTORIAL」（ショップのノルマの札・入金口・液晶。液晶には文を出さず、札・のこりプレイの玉・ゲージ・手持ち／納品額）。
- **はじめての挑戦（案内つき。`save.quota.guide`）**の流れ（`tutorialState(save).key`）：
  | 鍵 | いつ | 案内（ピエロの吹き出し・光る枠・指） |
  | --- | --- | --- |
  | `launch` | 1 プレイ目の前 | 台の上に吹き出しと、引っぱって離す手の動きの絵（`showLaunchHint`。文字は出さない） |
  | `sling` | 1 プレイ目のあと | RESULT の「ショップ」（黄のボタン。PC は「台へ」）→ フッターのショップ（PC は左の列を光らせる）→ 最上段の `data-toy="sling"` → 見本の「買う」 |
  | `again` | 買ったあと | フッターのピンボール → 台の上に吹き出しと手の動き |
  | `inlane` | 2 プレイ目のあと | ③と同じ順で④内側の通路 |
  | `deposit` | 3 プレイ目のあと | 入金口の「納める」（50 に届いていても 3 プレイ遊ぶまでは納められない） |
  | `bumper` | 納めた直後（ノルマ 1 の 1 プレイ目の前。`save.quota.tutJust`） | ごほうびのエンブレムで⑦丸いばね（ノルマ 1 の最上段にかならず並ぶ。`toys.ts` の `tutorialAfter`） |
  | `start` | ⑦を買ったあと | 台を見せたときに「本当のノルマ」のひとこと。打ち出すと案内はおしまい |
  - ⑦を買う番までは、ショップのほかの段・手元・ほかのギミックを暗くして触れなくする（`shopLocked`。`.sh.tut-lock`）。打ち出しは止めない（買わずに遊んだら、次のプレイのあとに前の部品が先に並ぶ）。
  - 文は短く（`TUTORIAL_LINES`。各場面 3 つ。コモンの小ばかの口調）。吹き出しは 1 回目のタップで文を最後まで、2 回目で閉じる（光る枠と指は残る。光る枠は黄と墨の切り取り線が回る）。小さな札「とばす ▸▸」（高さ 44px。aria-label は「案内をとばす」）で案内をやめる（`skipTutorial`：ふつうのノルマ 0 になり、③④⑦がまとめて並ぶ）。RESULT の間は吹き出しを画面の上に出して、入金口の数字を隠さない。プレイ中・演出（NEW GIMMICK!・ガチャ・進化）・Limited の選択・解説モード・設定の間は出さない。
  - 状態はセーブから決まるので、閉じて開き直しても続きの手順から出る。
- **2 回目からの挑戦**：案内なし（`save.tutorialDone`）。③④⑦がまとめて最上段に並び、50 に届けば早く納めてよい（早いほどエンブレムが多い）。

## 挑戦のサイクル（ノルマ・入金口・エンブレム。`src/game/quota.ts`）
数値と判定は純粋なモジュール `quota.ts` にまとめ、`tests/quota.test.ts` が見る。セーブの `save.quota`（いまのノルマ・使ったプレイ・リロール回数・選び残した Limited など）に挑戦の状態を持つ。
- **ノルマ 0（チュートリアル）**：挑戦のはじめにいつもある練習のノルマ（納品額 50・3 プレイ・GAME OVER なし・Limited なし。上の「チュートリアル」）。
- **ノルマ**：本編は 10 ノルマ（`QUOTAS`）。納品額は 200 から毎回 4 倍（200・800・3200・…・200×4^9。`quotaAmount`）。各ノルマは **3 プレイ以内**（`QUOTA_PLAYS`）。プレイは始めた時点で 1 つ使う（途中で閉じても戻らない）。
- **入金口**：プレイのあとの RESULT で GUM の発表（合計がぶつかる）のあと、同じ舞台に入金口が出る（`main.ts` の `renderQuota`。`.quota.dp[data-state]`：`pay` 納められる・`wait` まだ遊べる・`short` 足りない・`last` 足りないまま最後の 1 プレイ・`over`・`final`）。文は置かず、ノルマの札・のこりプレイの玉（余らせるとエンブレムになる玉に青緑の印）・エンブレム（+このプレイ分）・ゲージ（発表した額が流れこむ）・手持ち／納品額・不足（−n の血の札）で見せる。
  - 手持ちがノルマ額以上なら「納める　−額 ▶ エンブレム +n」（`.deposit[data-act="deposit"]`）。押すと手持ちからノルマ額を引き、GUM の玉が入金口へ吸いこまれてゲージが空になり、**PAID の判**（`beat('deposit')`）→ **CLEAR の判**（QUOTA n CLEAR!。エンブレムが転がって増える・余らせたプレイの玉・札「NEW ギミック ×n」「LAST STAGE」「DOOR OPEN」「おまけ +n」・ピエロのセリフ・歓声・振動）を出して、次のノルマへ。
  - **黄のボタンは 1 つ**（`setResGo`）：納められる → 納める／それ以外 → 台へ／チュートリアルで次の部品を買う番（スマホ）→ ショップ。ボタンで出るときは斜めの帯のワイプ（`leaveResult`）。
  - 足りなければ不足の札（−n）とのこりプレイの玉。足りているのに納めず、残りのプレイを遊ぶのは可（早く納めるほどエンブレムが多い）。
  - **3 プレイ目のあと**：足りていれば必ず納品（ほかのボタンは出ない）。足りなければ **GAME OVER**。
  - 3 プレイを使いきった状態で閉じたときは、次に開いたときに入金口（または GAME OVER）が出る（`checkQuota`）。プレイが残っていても、納められるのに納めずに閉じたときは、開いたときに入金口を出す（遊びつづけてもよい。`main.ts` の `resume`）。
  - ノルマ 10 を納めたときにピエロがジョーカーなら **ラストステージ**、ジョーカーでなければ **通常のエンディング**（上の節）。
- **エンブレム**（買い物の通貨。青緑の盾の印。上の HUD・ショップ・ラボ・スキルツリー・RESULT に数を出す）：1 プレイごとに必ず +1、ノルマ n の達成で **8.5 ＋ 0.25 ×（n − 1）の切り捨て**（ノルマ 1〜2 で 8、3〜6 で 9、7〜10 で 10。チュートリアルは `TUTORIAL_REWARD` 3＝⑦丸いばねとノルマ 1 の部品 2 つぶん。`quotaReward`・`EMBLEM_PER_QUOTA`・`EMBLEM_QUOTA_STEP`）、余らせたプレイ 1 つにつき +2（`quotaEmblems`）。序盤は部品とエクステンションの両方を買えるように厚く、終盤はゆるやか（エクステンションの重ねの伸びが大きいので、終盤のエンブレムを増やすと雪だるま式に楽になる）。使い道はギミック・エクステンション・ヒーローのガチャ・マレット・枠・スキルツリー。
  - エンブレムを増やす効果（`playEmblems`・`quotaBonus`）：Limited「真・王妃の黄金時計」（プレイごとに +1・時間 −3 秒）・「コボルドの黄金ブーツ」（G-U-M の大当たりのたびに +1、1 プレイ 2 まで）・「可愛い金魚」（納品 +2）・「真・冕冠」（納品 +4・プレイの +1 がなくなる）・「真・雨夜手拍子」（壊れるたびに +3）、エクステンション「両替の杖」（プレイのあとに +1〜3）、スキル「納品のごほうび」（納品 +3/段、5 段まで）、レジェンダリーからあふれた重ねの点（1 点 +1）。

- **装備の枠**：エクステンションは 3 枠、ヒーローは 1 枠から。ショップでエンブレムを払って広げる（エクステンション +1 は 6、ヒーロー +1 は 5。どちらも 5 まで）。**枠を増やす効果を持つ Limited やエクステンションで、さらに増える**（ユーザーの指定：装備できる品が増え、倍率の伸びしろが増える）。エクステンションの枠は Limited「真・グランダルメ」+1・「真・無銘金重・了戒」+2、エクステンション「そろいの衣装」「空き枠のお守り」（装備している間。★で +1・2・2・3・4、自分の枠をふくむ。`SLOT_VALS`）で、8 まで（`EXT_SLOTS_CAP`）。ヒーローの枠は「真・雛人形」+2 で 6 まで（`slotsOf`）。枠を広げる品を売る・壊れるなどで枠が減ったら、はみ出した品を右から売る（`fitSlots`。入れかえで売るときは札に「枠 −n」と出す）。ヒーローの枠が 2 つ以上なら、控えのヒーローもはじめから球になって台に出る（下の「控えの球」）。

- **GAME OVER で失うもの**（`resetChallenge`。プレイヤー名・脱出の記録も残る）：GUM・エンブレムの使い残し・装備のエクステンション（重ねた点も）・**マレットのレベル**・**買ったギミック（部品と仕掛け。台は打ち出しとフリッパーだけに戻り、ピエロはコモンに戻る）**・**ガチャで出たヒーロー（はじめのヒーロー `save.starter` だけに戻る）**・Limited・ヒートの印・エクステンションの育ち・広げた枠・ショップの品ぞろえ（ガチャのカプセルも）・挑戦の進み（ノルマ 0（案内なしのチュートリアル）・TABLE 1 に戻る）。**残るのはスキルツリー（`save.up`）と設定、図鑑の記録**（`save.exts`・`heroDex`・いちばん先の台 `pinRecord` など）。ノルマをまたぐだけなら何も消えない。

- **数値の合わせ**（ユーザーの指定：ノルマの 4 倍・各 3 プレイは変えず、効果の強さとエンブレムの量で合わせる）：

## 操作

| 操作 | 動き | 実装 |
| --- | --- | --- |
| 傾ける | 傾けた角度で速さが決まる（加速し続けない）。少し傾ければゆっくり、約 27 度（`TILT_FULL`）で最大の速さ `stats.tiltSpeed`。水平に戻せばすぐ止まるので、画面のまん中で敵を追いかけられる | `src/core/sensors.ts` の `tilt()`、`world.ts` の `step` |
| 水平リセット | いま持っている角度を「傾き 0」にする（始めたときにも自動で合わせる） | `Sensors.calibrate()`、画面左下のボタン |
| 振る | 振り始めの向きの速さに入れかえて一気に飛び出す（逆へ動いていても振った向きへ）。0.32 秒は次の振りを受け付けない（止めるときの逆向きの加速を拾わないため） | `Sensors.onMotion` → `World.shake` |
| 押して引っぱって離す | 画面のどこを押してもよい。引いた向きと反対へ、引いた長さに応じた速さで飛ぶ（`MAX_PULL` で最大、`MIN_PULL` 未満は取り消し）。押している間はマレットにブレーキがかかり、時間が 0.35 倍のスローになり、飛ぶ道すじ（壁で 2 回まで）が出る。傾き・振りは使わない | `main.ts` の pointer 系 → `World.holdStart/holdPull/holdEnd`、`render.ts` の `aimGuide` |
| PC | W・A・S・D（矢印キー）で傾き（押している間その向きへなめらかに傾き、離すと戻る。`KEY_TILT` 0.4・`KEY_TILT_TAU` 0.09 秒。斜めは 2 つを合わせ、反対どうしは打ち消す）、スペースで振り（1 回押すと 1 回。向きは押している WASD、なければでたらめ）、マウスで押して引っぱって離す（タッチと同じ）。マウスで引っぱっている間・打ち出す前は、キーの傾きと振りを使わない。入力欄に打っているときはキーを受けない | `sensors.ts` の `KeyTilt`、`main.ts` |

### 傾きの測り方
- 加速度センサー（重力込み）をなめらかにして「重力の向き」を出し、基準の姿勢からの回転として傾きを測る。
  寝かせて持っても、立てて持っても同じように効く（角度の差し引きではなく 3 次元の回転で比べる）。
- 端末によって加速度の符号が逆のことがあるので、最初の 30 回は傾きセンサー（deviceorientation）と見くらべて自動で合わせる。
  合わない端末向けに、設定に「傾き・振りの向きを反対にする」を置いている。
- 手ぶれで勝手に滑らないよう、傾き 0.025（約 1.4 度）までは遊びにしている（`main.ts` の `dz`）。
- iOS はタップの中でモーションの許可を求める必要がある。はじめて打ち出そうとしたときに許可をたずね、その 1 回は打ち出さない（左下の半券のトースト「センサーを許可／もう一度 引っぱる」。許可の画面の裏でプレイの時間が進まないように）。HTTPS でないと動かない。

### 攻撃の色（3 すくみ）
操作ごとに攻撃の種類と色が分かれている（`src/game/elements.ts`）。マレットのふちが、いまの攻撃の色に光る。**色だけで区別しない**：赤＝●の連打・青＝◇の輪・緑＝▲の矢（球やマレットのまわりの印と、当たった所の粒。`src/fx/attack.ts` の `attackMark`・`emitHit`。下の帯の `#mode` とスキルツリー・遊び方の「?」も同じ形）。

| 色 | 操作 | 攻撃 | 決まり（`world.ts`） |
| --- | --- | --- | --- |
| 赤 | 傾ける | 近距離・連続 | 敵の向きへ傾けて押しつけていれば、遅くても `stats.redInterval`（0.09 秒から。スキルで短くなる）ごとに当たる。強さは傾きの大きさ × `stats.redPress`。赤のときは敵に当たっても跳ね返らず（くっついて押しこむ）、壁でもほとんど跳ねない（0.3）。敵を追いかけて当て続けやすくするため |
| 青 | 振る | 範囲 | 振った場所から波が広がり（半径 `stats.area`）、ふちに触れた敵全員に 1 回ずつ当たる（× `BLUE_MUL`）。振ってから `stats.blueTime` の間はマレットの体当たりも青 |
| 緑 | 引っぱって離す | 貫通 | はじき返されずに突き抜け、線の上の敵全員に当たる（1 回のはじきで 1 体に 1 回）。`stats.greenTime` か、速さが `GREEN_MIN_SPEED` を下回るまで |

- 敵にも色がある。**赤い敵は青に、青い敵は緑に、緑の敵は赤に弱い**（× `WEAK_MUL` = 2.5、数字に「弱点!」）。弱点以外はすべて等倍（同じ色でも半減しない。ユーザーの指定）。
- 敵の足もとの輪が敵の色、頭の上の丸が「効く攻撃の色と、その操作の 1 文字（傾・振・引）」。
- ボスは `BOSS_ELEM_TIME`（7 秒）ごとに色が変わる。HP バーの右に、いま効く操作が出る。
- 仲間・玉突き・エクステンションの衝撃波は色なし（× 1）。
- **攻撃の届く範囲**（設定「攻撃の届く範囲を広く」、はじめは入）：体のふちより少し先（敵の大きさ × 0.62、最低 14）まで攻撃が届く。届く範囲ではぶつからず、近づいているとき・赤で押しつけているときだけ当たる（丸いマレットでも角の敵に当てられるように。`World.reachOf`）。
- **フィールドの形**（設定「フィールドを楕円にする」、はじめは四角）：楕円にすると角がなくなり、ふちの向きに合わせて跳ね返る（`World.ovalWall`）。どちらがよいか試すための切りかえ。

### 手ざわりの方針
- **指を動かす労力が少ないほど気持ちいい**。指をぐりぐり動かすのが最適解にならないこと。
  押している間に指を動かしても、マレットは動かない（ダメージも出ない）。飛ぶのは離した 1 回だけ。
- 当たった瞬間は一瞬止める（ヒットストップ：通常 0.03 秒、SMASH 0.07 秒、ボス撃破 0.18 秒）。画面の揺れ・振動・火花も合わせる。
- 飛ばしたエネミーが別のエネミーに速くぶつかると、両方にダメージ（玉突き、`CHAIN_SPEED`）。
- 当たりが 1.4 秒以内に続くと連続ヒット（COMBO）。50 連続まで、倒したときの GUM が最大 2 倍。
- 加速・最高速・はじく速さは `economy.ts` の `stats` の `accel`・`maxSpeed`・`shake`・`launch`。
  センサーのなめらかさ（遅れ）は `sensors.ts` の 0.03 秒（重力）と 0.02 秒（向き）。

## 実況（連鎖をほめる）
- 当たりが 1.4 秒以内に続くと連鎖（COMBO）。連鎖が進むほど実況が派手になる（`src/game/announcer.ts`）。
  - 2〜4 連鎖：Hmm... / Nice! など（間をあけて）、5〜9：Great! / Awesome! など、10〜19：Fantastic! / Gorgeous! など
  - **20 連鎖から最高潮**：Unbelievable! / Amazing! / Magic! など。しゃべり終わるたびに次を言い続け、画面のふちが虹色に脈打つ
  - 5・10・20・30・50・100 連鎖は区切りのことばを割りこんで言う。SMASH・弱点・ボス出現・ボス撃破・ステージクリア・連鎖の終わり（10 以上）・スキル取得にもひとこと
- 言ったことばは、擬音のようなド派手な文字（Bangers の書体・ぎざぎざの吹き出し・網点。色は様式に合わせて段階ごとに 骨 → 黄 → 血 → 紫）で出す（`src/ui/callout.ts`・`src/styles/g3.css`）。段階が上がるほど大きく、画面の光・揺れ・振動・歓声も付く。
- **実況しているのはジョーカー**（ユーザーの指定：ことばが画面を覆うと台が見えないので）。台を映す窓の右上にピエロのシリーズがいて（いまのピエロの姿の絵。ギミックを買い足すほどレアリティが上がり、最後はジョーカー（5063）に戻る）、ことばはその左（画面の上の右寄り）に、もとの 7 割ほどの大きさで出す。新しいことばはいつもジョーカーの口もとの段に出て、前のことばは下の段へずれて小さく・うすくなる（同時に 2 つまで）。長いことばは入る大きさまで縮める。
  - ジョーカーが言うのは実況のことばだけ。ピンボールの仕掛けの名前などの知らせ（GRAB!・UFO 1 / 3 など）は上の電光掲示板に出るので言わない（ユーザーの指定）。大きな知らせのときは、ことばなしで跳ねて盛り上がる。
  - ジョーカーは待っている間もゆれ、しゃべると口もとから音の波が出て体がゆれる。段階 0 は小さく跳ね、1 は跳ねて左右に傾き、2 は大きく跳ねて震え、光の輪が広がる、3 は震えっぱなしで後ろの光が虹色に回る。20 連鎖からの最高潮では、しゃべっていない間も跳ね続ける。
- 連鎖のたびに音が上がる（いまの曲の調の 5 音の音階を上る。`audio.ts` の `chime`。下の「音」）。上の帯の時間のとなりにも連鎖の数（×n）が出る。
- 声は ElevenLabs で作った英語の実況（`src/core/voice.ts`）。設定の「実況の声」で消せる（消しても文字は出る）。しゃべっている間は BGM を下げる。

## ピラミッド（ピンボールの中のボーナスステージ・15 秒・50 階。クリア後のエンドレスだけ）
- 本編では入口が閉じている（`save.endless` が false）。コードは残し、エンドレスモードで開く。
- ピンボールの入口から入ると始まる。1 回は **15 秒**（`RUN_TIME`）。時間切れ（または 50 階突破）でピンボールにもどり、入口から球が飛び出す（`PinballWorld.returnFromPyramid`）。ピラミッドにいる間、ピンボールの時間は止まる。
- 階に入るとエネミーがまとめて出る（`enemiesOnFloor`：3 + 階/4 + スキル「エネミーの数」）。ぜんぶ倒すとボス、ボスを倒すと下の階へ。
- ボス：10 階ごと（10・20・30・40・50 階）はレイドボス、ほかの階はシャドーヒーロー（ゴースト化した英雄）。
- **ピラミッド**：下の階ほどフィールドが広い（1 階ごとに `FLOOR_GROW` = 1.1 倍、50 階でおよそ 107 倍）。フィールドの幅は画面のまま、マレットの大きさを `floorScale` で小さくして表す。
  **マレット以外はみんな大きくなる**（ユーザーの指定）：エネミー・ボスは縮まない。波・磁石・仲間はマレットほどは縮まない（`floorScale` の 0.3 乗、`World.zs`）。
  マレットが画面で 14px より小さくなると、まわりに目じるしの輪を出す。スキル「マレットの大きさ」（最大 45 段）で取り戻す。
  階を突破すると、いまのフィールドが一回り縮んで新しい階のまん中に収まり、まわりに新しい階（新しい背景）が広がる（`zoom` の間は時間が止まる。上の階のふちはピラミッドの段として薄く残る）。
- **つぶす**：敵がまるごとマレットの下に入ったら一撃で倒れる（CRUSH!）。マレットを大きくするほど浅い階は一瞬で終わる。フィールドより大きいマレットは画面のまん中に置き、画面全体をおおう。
- **免除**：0.1 秒未満（`FAST_CLEAR`。3 コマ以内も一瞬とみなす）で突破した階は、1 階から続くぶんだけ次のランからとばす（`startFloor`）。
- 50 階のボスを倒したら全クリ（ALL CLEAR）。そのあとも上の階を一瞬で駆けぬけて GUM を集められる。
- ランが終わると、落ちている GUM や品はぜんぶ手に入る。
- ダメージ＝攻撃力 ×（ぶつかった速さの倍率）。速さ 2400 以上は「SMASH!」で 1.5 倍（`economy.ts` の `impactFactor`・`stats.smashSpeed`）。
- 倒すと GUM が散らばる。マレットか仲間が触れると拾える。9 秒たつと自動で吸い寄せられる。
- たまにエクステンションを落とす。拾うと 12 秒の強化（攻撃 ×2・GUM ×2・強力磁石・加速・巨大化）か、その場で全体攻撃（衝撃波）。
  初めて拾った種類は図鑑に載り、1 種類ごとに攻撃力 +1%。
- レイドボスは必ず、ほかのボスはときどきヒーローを落とす。手に入れたヒーローはマレットにでき、仲間としても出てくる。PHY が攻撃、INT が GUM、AGI が滑りやすさを上げる。
- スキル「マレットの大きさ」は 1 段ごとに 12%（最大 45 段）。深い階へ進むほど大きくしたくなる。

## ピンボール（ゲームの本体。`src/game/pinball.ts`・台の形は `src/game/table.ts`・描画は `src/game/render-pinball.ts`）
コンセプトは「打ち出したあとに干渉できるピンボール」。GUM・スキルツリー・ヒーローはピラミッドと共通。

- 台：幅 720・高さ 1280（画面に収まる大きさの 4 倍の広さ。ユーザーの指定：幅 2 倍×高さ 2 倍）の、手前へ下るゆるい坂（`GRAVITY`）。
- **カメラ**（ユーザーの指定：追いかけ＋速さで引く）：球を少し先回りして追う。速いとき・ランプの上・マルチボールや控えの球が出ているときは引いて広く（本物の球がぜんぶ入るまで。いちばん引いても台全体まで）、ボスのそばでは少し寄り、ブラックホールや入口に吸いこまれるときは寄る。プレイの始まりと台の突破では台全体を映す。右下に小さな全体図（映している範囲・球・的・ボス・入口・ブラックホール）。
- **1 回のプレイは 40 秒**（`PIN_TIME`）。球が止まっているとき（打ち出し待ち・ロックのホール）だけ、引っぱって打ち出せる。
- **打ち出しでプレイが始まる**（ユーザーの指定：ゲームの UI ボタンは極力なくし、現実のピンボールと同じように遊び始める）。「はじめる」ボタンはない。
  - ピンボールのページを開く（スマホはフッターの「ピンボール」、PC は遊んでいない間ずっと）と、`main.ts` の `arm()` が台を組み、リーダーの球を打ち出しの通路に置く（`PinballWorld.waiting = true`：時間・台の仕掛けは進めず、明かりと演出だけ動かす）。プレイの数もエンブレムも、まだ動かない。
  - 引っぱって離し、球が通路を出た瞬間（`launched()`）にプレイが始まる：プレイを 1 つ使い、エンブレム +1、集計を開き、BGM・TABLE n の帯、フッターを隠す。打ち出しの GUM・スキルショットもこのプレイの集計に入る。`save.runs` は打ち出したプレイだけ数える。
  - 打ち出す前は、傾け・振りでは何も起きない。通路の球は「下へ引いた分」だけを引っぱりにする（横の動きの 0.6 倍を差し引く。横へのスワイプでうっかり打ち出さないように）。
  - 打ち出す前の台：液晶（`src/ui/dmd.ts` の `setDmdInfo` → `render-pinball.ts` の `drawDisplay`）に、**文ではなく絵で**「ノルマの札（`QUOTA n`・`TUTORIAL`・`ENDLESS n`）＋のこりプレイの玉／ゲージ＋手持ち／納品額」と「台の番号＋引っぱって離すの小さな絵」を交互に出す。ラストステージはボスの数のひし形、プレイを使いきっていれば `DEPOSIT`（台に触ると入金口へ）。ボス台の掟は名前だけ。右上のピエロがひとこと、しばらく打ち出さないと引っぱって離す手の動きの絵（`src/ui/ready.ts` の `showLaunchHint`。はじめての人にはすぐ。文字は出さない）。上の ? で遊び方の吹き出し（`initHelp`。PC はマウスを乗せると開く。絵 3 コマ「引っぱる・傾ける・振る」＋攻撃の形＋ 2 語と、3 すくみ ◇ → ● → ▲ → ◇。ルールの文は置かない）。
  - 入金口・GAME OVER・ラストステージの口上・Limited やヒートの選択・導入などが出ている間は台を組まない（`blocking()`）。閉じたら自動で組む（`syncReady()`）。RESULT のボタンは「台へ」。
- **はじめの台は打ち出しとフリッパーだけ**（ユーザーの指定）。ほかの部品はすべて買い足すギミック（下の「ギミックとピエロの成長」）。買っていない部品は描かない・当たらない・GUM を出さない（`PinballWorld.buildTable()`。`table.ts` の `SegDef.part`・`unless`、`LightPath.part`）。
  - 外側の通路を買うまでは、左右の坂の下からフリッパーの根元まで流しこむ坂（エプロン `T.APRON`）があり、外へ落ちる道がない。外側の通路を買うと、エプロンが消えてインレーンの仕切りになる。
  - 何もない台でも止まった画面にしない：フリッパーで打ち返すと白く光ってラジアルの光（`Flipper.flash`）、外のふち・金属のガイドに強く当たると光る（`Seg.flash`）、打ち出すと通路が光って音。液晶の状態の行は持っている部品だけ（何もない台では「FLIP n」＝打ち返した回数）。
  - 何もない台でも GUM が出る（出どころ `flipper`・`plunger`・`wall`・`inlane`・`outlane`）。
  - 部品どうしのつながり：的（targets）を買うまでは的もボスも出ない（台は TABLE 1 のまま。ラストステージはいつもボスが出る）。ロックだけ（球が増えるなし）なら止めて狙って撃てるだけ。ジャックポット・ZONE・ブラックホール・ゴーストスター・ボールセーブは、その部品を持っているときだけ。ミステリーの当たり・オファーも、台にない部品にふれるものは出ない（`mysteryReady`・`offerReady`）。
- **打ち出しは右端の細い通路（シューターレーン）から**（ユーザーの指定：実際の台と同じ側面からの打ち出し）。球は通路の下（`T.PLUNGER`）に置かれ、引っぱって離すと、引いた強さでまっすぐ上へ飛ぶ。右の通路を駆け上がって台の上を回り、左の通路から台の中へ入る（打ち出しで上がった分はループと数えない）。
  - 強さ 3 割くらいまでだと上まで届かず、通路を落ちて戻ってくる（RE-SHOOT。ボールは減らない）。
  - 通路の出口には片側だけのふた（`oneWay` の壁）。上から下りてきた球は坂として台の中へ流し、打ち出しの球だけを通す。
  - 引いている間は、通路の左に強さのメーター。下のばねが縮む。
- **控えの球**（ユーザーの指定：ヒーローの枠が 2 つ以上なら、はじめから複数の球で遊べる。`pinball.ts` の `queueReserves`・`stepReserves`）
  - 打ち出しの通路からリーダーを打ち出すと（プレイの始まり・球が全部落ちて打ち出し直すとき・弱くて戻ってきた打ち直し）、**台に出ていない控え**が編成の順に、右の通路から **0.4 秒おき**（`RESERVE_GAP`）に 1 つずつ自動で打ち出される。いつも台の上まで届く強さ（`RESERVE_SPEED`）。押して引っぱって離すのはリーダーの球だけで、操作はふえない。同じヒーローの控えの球が 2 つ台に出ることはない。
  - 知らせ：電光掲示板に「PARTY BALL 2 / 4」（控えの名前）、打ち出しの音（続くほど高い）・通路の下から上へ流れる光・緑の輪と火花・小さな振動。通路を駆け上がる間、控えの球は緑に光って尾を引く。
  - 控えの球はそれぞれのヒーローの絵で、そのヒーローの能力（台に出ている間だけ効く）で動く。台の上での扱いはマルチボールの仲間の球と同じ（バンパー・的・ライト・ブースター・ワープ・キックバックなどに当たる。ランプ・ロック・ミステリー・ループ・入口・仕掛けの中へ入るのは本物の球だけ）。傾けると少し曲がる（下のフリッパーのあたりでは曲がりにくい）。弱くて通路を落ちてきたら自動で打ち直す。同じ場所に 2.5 秒いたら、はじき出す（はさまって止まらないように）。

  - **リーダーの球（本物の球）が落ちた**：ボールセーブ・予備のセーブ・マグナセーブが先に効く。効かなければ、台に仲間の球（控えかマルチボール）が残っているかぎりプレイはそのまま続き、残った球の 1 つが本物の球を引きつぐ（PLAY ON!。絵はそのヒーローのまま。引きついだヒーローの能力も台に出ている扱いで効き、リーダーの能力はいつも効く）。カメラはいつも本物の球を追う。**球が全部落ちたときだけ DRAIN**（倍率が 1 に戻り、落とした回数に数え、打ち出しの通路にリーダーが置かれる）。
  - ヒーローの枠が 1 のとき（または控えがいないとき）は、これまでと同じ 1 球のピンボール。
- **球の数の上限**（重くならないように）：本物の球（自分の球・控え・マルチボールの仲間）は **12 個まで**（`MAX_REAL`）、分身もふくめた全部で **16 個まで**（`MAX_BALLS`）。控えは最大 5 つ（枠 6）なので、控えが全部出ていてもマルチボールで 6 個以上増やせる。マルチボールで分身が場所をふさいでいるときは古い分身から消す。16 個でも 1 コマの計算は 0.3 ミリ秒ほど。

### GUM の発表（プレイのあと。集計は `src/game/tally.ts`・画面は `src/ui/payout.ts`）
ユーザーの指定：1 回のプレイで楽しみを 2 回にする。プレイ中は台の演出と音を楽しみ、プレイが終わってから、そのプレイがいくらになったかを派手に発表する。
- **プレイ中は GUM を財布に入れない**。出どころ（バンパー・三角のばね・スピナー・レーン・ランプ・ループ・ジャックポット・的・ボス・仕掛けごと・ピラミッド・改造のボーナスなど。`GumSrc`）ごとに、回数と「基本額」をためる。上の GUM の数字は動かず、財布に封ろうの印が付く（`.gum.sealed`。文は出さない）。台の上の「+いくら」の数字も出さない（演出と音は出す）。
- 出どころには、何もない台でも出るもの（フリッパーで打ち返す・打ち出し・ふちに強く当たる・内側の通路・外側の通路のなぐさめ）もある。
- 基本額にはその場の倍率だけが入る：GUM ×N のランプ・ZONE の ×2・台のはじめの GUM（夜明け）・色の GUM・ループで上がった台の GUM・GUM のアイテム・連鎖・控えのヒーローの能力。
- プレイが終わると、まず **TIME UP!**（全クリは ALL CLEAR!!、脱出は ESCAPE!!）の見せ場（墨の三角が上下からかみ合って閉じ、判が押される。`beat('timeup')`。BGM は止めの一発のあと 1.5 秒黙って RESULT の曲）、そのあと **RESULT** で GUM を発表する（ユーザーの指定）。RESULT はカードではなく画面いっぱいの舞台（`src/styles/show.css`）。
- **最後の額 ＝ 基本額 × 倍率**（`settle`）。倍率は 1 から始まる。
- **発表の形**（`src/ui/payout.ts`。掛ける中身は `PinballWorld.gumBoosts()`）：**文は置かない**（札の名前と効き目は `data-tip`・`aria-label`）。触ると早送り（合計のぶつかりからは必ず見せる）。
  1. **レシート**：入金口から刷られる紙に、出どころごとの「回数」と「基本額」が少ない額から 1 行ずつ。基本額が転がって増える（行ごとに音が上がる）。
  2. **Limited の出どころの倍率**（バンパーの GUM ×2 など）とエクステンションの「行 ×」：その出どころの行だけに掛かる。レシートの行に判が押されて額が増える。
  3. **並んだ札**：装備のエクステンションが**装備の並び順に左から 1 つずつ**発動する（ユーザーの指定：全体のスコアに掛かる。×2 と ×3 なら ×6。発動順を工夫する要素）。+基本額は基本額へ足し、+倍率は倍率へ足し、×倍率は倍率に掛ける。だから「+倍率 → ×倍率」の順に並べると大きくなる。札の頭には、Limited で付けたヒートの印の分（炎の札。印の部品に当たった回数 × 1 回ぶん）が +倍率で入る。
     - 動きは種類で違う（どの品が何に効いたかが動きで分かるように）：+基本額＝弧を描いて基本額へ／+倍率＝まっすぐ倍率へ／×倍率＝まん中で大きくなって叩きつける（ゆれ）／行 ×＝レシートの行に判／エンブレム＝上の印へ。こだま＝輪が 2 つ、うつし鏡・王冠の写し＝札が裏返る。条件を満たさなかった札は震えて伏せる。
     - 種類の印は形も変える（四角に＋・丸に＋・ひし形に×・横長に×・青緑のひし形）。
  4. **全体の倍率**：スキルツリー（GUM の枝・ヒーローのボーナス）→ Limited の GUM（1 つずつ。おみやげもここ）→ リーダーの能力（倍率の供給・貯金箱）→ 取引の GUM ×2。札の右に丸い印として足され、倍率に掛かる。
  5. **合計**：基本額（骨の紙）と倍率（血の板）がぶつかって 1 つの額（チケット黄）になる。ここで財布に入る（上の GUM が転がって増える）。合計の段（`tier`）で見せ方が変わる：0 ふつう／1 大きい（ノルマの半分以上）／2 記録更新（`save.quota.bestGum` より大きい。判 NEW RECORD）／3 ノルマを一気に納められる（判 QUOTA OK!）。数字は桁で大きく・色が変わり（`heatOf`）、小数と K・M の単位は小さく添える（`payNum`）。
  - 育つ品は、育った回は札に ▲ と段。壊れものは、効いたあとに決まった確率で割れて落ち、装備から消える（そのプレイの効果は効く。Limited で直るときは光る）。壊れるかどうかはプレイのあとの発表で 1 回だけ決める（途中の見込み `pendingGum` では壊れない）。エンブレムを生む品は上のエンブレムの印へ飛び、プレイのあとに足される。
  - 音：掛かるたびに音が上がり（`sfx('count'|'mult'|'stamp'…)` の step）、合計で `fanfare`・`jackpot` と `music.hit`。
- 合計のあと、記録の札 2〜3 枚（TABLE・COMBO。ラストステージは BOSS n/5、エンドレスのピラミッドは FLOOR）と**入金口**が出る（上の「挑戦のサイクル」）。ボタンは「ショップ」「ラボ」「台へ」。
- プレイの途中で閉じても GUM が消えないよう、倍率まで掛けた見込みを 5 秒ごとにセーブへ残し（`pendingGum`）、次に開いたときに受け取る。プレイが終わった瞬間に、発表する額そのものに置きかえる（発表の途中で閉じても同じ額）。
- 解説モードの実演では GUM は入らない。

### 台の見た目（ずっと見ていたくなる台。`src/game/render-pinball.ts`・`src/fx/`）
様式は UI と同じ「呪われたカーニバル」：木の盤面・サーカスのテント・真ちゅうと電球。**台が直るほど絵も直る**（ピエロの段階 0〜4。`<html data-clown>` を `src/fx/quality.ts` が読む）。
- **盤面の絵**（`src/fx/board.ts` の `paintBoard`。動かない部分を 1 回だけオフスクリーンに描き、映っている所だけを貼る）：木の板・木目・ニス・テントの天幕・円形の舞台・ハーレクインのひし形・スート・星・リボンのロゴ・ステージの絵を入れた丸い額。台の外はビロードの幕。段階 0 は色あせ・はがれ・ひび・しみ・くもの巣、上がるほど色が戻り、4 は金の粉。
  - **動かない金物は盤面の絵に焼きこむ**（`paintFixtures`：壁のレール・柱・三角のばねの板・外のふちの真ちゅう・電球のソケット・打ち出しの通路の板・ランプの支え）。毎コマ描くのは「光った所」だけ。
  - **はじめの台の見どころ**（段階 0・1。`paintRelics`・`drawRelics`。段階 2 から消える）：色あせたピエロの絵看板（片目がはがれている）と、その上の消えたネオン管「G U M」（段階 0 はときどきジジッとまたたき、段階 1 は点いていてときどき落ちる。`html.calm` ではまたたかない）。
  - **次に買える部品の跡**（`nextToys`：入荷の順でまだ持っていないはじめの 3 つ）：日焼けしていない跡とねじ穴を本当の形（`toyOutline`）で描き、打ち出しを待つ間かすかに息をするように光る。
  - 取っておく絵の鍵に `document.fonts.status` を使わない（和文の書体はかけらごとに読みこまれ、そのたびに盤面を描き直して 0.2〜0.3 秒止まり、音符も抜けた）。`src/fx/bake.ts` の `headFontsReady()`（見出しの書体が読みこめたら true のまま）を使う。盤面の細かさは、はじめに描いたときの画質のまま変えない。
- **作っておいた絵を貼る**（`bake.ts` の `baked`・`stamp`）：丸いばね（真ちゅうの輪・テントの縞・ガラスの帽子）・フリッパー（くさび形。振り抜きの弧）・穴の受け皿・球の縁・ヒーローのメダル・液晶の中身（変わったときだけ描き直す）・ランプの入口・仕掛けの台座と名札。大きな仕掛けは共通の部品で描く：`plinth`（真ちゅうの輪の木の台座）・`plaque`（チケットの名札。1 語）・`pips`（進みぐあいの電球の列）・`shelfSprite`・`cupSprite`。
- **台の上に説明の文を出さない**（数字と形で）：跳ね橋の進み＝電球、「中へ」＝流れる矢印、大砲のねらい＝点線と残り時間の輪、カエル＝赤いふち、怪物がかむ＝牙、口が開く＝アーチの電球が虹色。打ち出しの通路は SHOOT の札と矢印とばねの握りが動く（「引っぱって打ち出す」の文は消した）。プレイ中にはじめて触れた部品の名札は名前だけ（骨の紙の小さな平行四辺形が弾んで出て 2.4 秒で消える）。
- 外のふちは真ちゅうのレール＋電球（段階で切れた電球が点く）。球は下の暗がり・光・つぶれ／のび・残像・攻撃の形の印（●◇▲）・カメラが引いたときの目じるし。ガラスの映りこみ・スポットライト・のこり 5 秒の鼓動のふち。
- ランプ（色ガラスの矢印・星・四角）：ゲームの状態で点く（ループ・ランプ・ホール・的・インレーン・SHOOT AGAIN など）。
  ライトショーの合図（`Show`：広がる輪・下から上へ流れる帯・点滅・虹・赤く消える）で、知らせのたびに台じゅうが光る。打ち出し待ちの間は、ゆっくり色が流れ続ける。
- 全体の光の色がモードで変わる：ふつうは青白、ボス中は赤、ブラックホール中は紫、マルチボールと ZONE は虹。マルチボール・ZONE・大きな知らせでは、上からレーザーが走る。ジャックポットなどで画面が一瞬寄る。
- **当たりの手ごたえ**（`src/fx/table-fx.ts`。台ごとに状態を 1 つ）：球の速さの急な変わりを当たりとして、火花・閃光・ほこり・球のつぶれ／のび・当たった向きへ押されてばねで戻るゆれ・衝撃波。部品の光りはじめ（丸いばね・三角のばね・フリッパー）で部品らしい粒。見せ場（大当たり・マルチボール・ZONE・ボス・のこり 5 秒・TIME UP）。打ち出す前もほこり（段階 4 は金の粉）が舞う。粒子は `src/fx/particles.ts`（席を使い回す。上限は画質 高 640・中 360・低 140）。ピラミッドの当たりは `World.fxq`（`fxEv`）で描画へ知らせる。ヒットストップの長さは「手ざわりの方針」のまま。

- **重くならないように**：canvas の影ぼかし（`shadowBlur`）は使わない。光は作っておいた絵（`src/fx/sprites.ts`）を重ねる。台の形での切り抜きはしない（ふちの近くの光は幕の上へ少しもれる）。大きなにじみ（半径 22 より大）の足し算と、盤面を縮めて貼るときのなめらかさは画質「高」だけ。ピンボールは画面の細かさを 2 倍までにする。画質の段階は下の「画質と演出の設定」。
- 台の上に液晶ディスプレイ：知らせは名前だけを大きく出し（説明の 2 行目は描かない）、ふだんは台の様子（G・U・M・LOCK・RAMP・残りの的。持っている部品だけ。何もない台では「FLIP n」）、入口が開いている間はのこり時間、打ち出し待ちの間はノルマの札と玉とゲージ（上の「打ち出しでプレイが始まる」）。右に GUM の倍率。
- **音や演出がない場所・止まった画面を作らない**（ユーザーの指定）。はじめの台（打ち出しとフリッパーだけ）にも、打ち出し・フリッパー・ふちの光と音がある（上の「はじめの台」）。
- **通り道のライト**（買い足す部品「小さなライト」。`LIGHT_PATHS`。外側・内側の通路などの道は、その部品も持っているときだけ）：左右の通路・上の弧・左右の坂・アウトレーン・インレーン・まん中の道・V 字の道・バンパーのまわり・入口のまわり・ホールの下に、小さなライトを並べる。球（仲間・分身もふくむ）が通ると灯り、灯るたびに「ピッ」。続けて灯るほど音が高くなる（0.4 秒あくと元にもどる）。灯りは 5 秒で消える。1 本の道が全部灯ると白く点滅して GUM（LIGHTS）。消えているライトにも、道にそって光の粒がゆっくり流れる（いつも画面のどこかが動く）。
- ワイヤーのランプのレールにも LED。ふだんは光が流れ、球が走ると後ろが白く灯ってピピピと鳴る。
- 落とし物はその場ですぐ手に入る（台の上に散らからないように）。

### 画質と演出の設定（`src/fx/quality.ts`・`src/ui/kit/stage.ts`）
- 設定（`save.settings`）：`quality`（画質 高・中・低 → `<html data-q="high|mid|low">`）・`calm`（「ひかえめ」→ `html.calm`。未設定なら prefers-reduced-motion に合わせる。点滅・ゆれ・画面全体の光を弱め、ワイプと見せ場は短い暗転に）・`bigText`（「大きな字」→ `html.big`。kit の字の変数が 1.15 倍）。BGM と効果音の音量のつまみ（`bgmVol`・`seVol`）。
- 段階：高＝後がけ全部（ぼかし 2 回・色ずれ・ざらつき）・粒 640・残像／中＝後がけ（ぼかし 1 回・色ずれなし）・粒 360／低＝後がけなし（2D のまま）・粒 140・盤面の木目と傷を減らす・ほこりなし・UI の飾りの動きを止める。
- **自動で上げ下げする**（60fps をめざす）：「中」から始める（前回の結果を `localStorage` の `mycryptosmash.fxq.v1` に覚えていればそこから。セーブとは別で `?reset=1` では消えない）。下げるのは早く（コマの間隔の平均が 34ms より重ければ 0.25 秒、26ms より重ければ 0.5 秒、21.5ms より重ければ 0.9 秒）、1 コマだけの引っかかりでは下げない。余裕（17.6ms 未満）が続けば上げる。重くて下げた段階より上へは 3 日間上げ直さない。設定の画質は上限。
- 実機（スマホの GPU）での後がけの重さと見え方は、まだ確かめられていない（測った数字は GPU なしの環境のもの）。


## 遊んでいないときの画面（ショップ・ピンボール・ラボ。`src/ui/home.ts`）
遊んでいないときは 3 つの画面（ユーザーの指定。開いたときは、まずホーム画面：上の「ホーム画面」）。スマホは下のフッターで切りかえ（ショップとラボのページは左右のスワイプでも。ピンボールのページでは指の動きは打ち出しの引っぱりなので、スワイプで切りかえない）。プレイ中はフッターもスワイプも使えない。フッターは 3 枚つづりのチケット（「ラボ」に取れるスキルの数。プレイが始まると下へ引っこむ）。
- **ショップ**（左。`src/ui/shop.ts`・`shop.css`）：切り絵の人形劇の舞台（墨の箱・骨の縁・テントの縞の幕と三角の旗・4 段の棚。値札は破れたチケット。リストにしない）。**スクロールしない**（ユーザーの指定。どの画面の大きさでも 1 画面に収める）。
  - 上の帯：ノルマの札（触ると数字だけの吹き出し：GUM a / b・のこり n プレイ）・GUM・エンブレム。
  - **ピエロの段階で舞台も直る**（`html[data-clown]`）：0＝幕が破れて短い・留め具が外れている・棚が傾いている・蜘蛛の巣・ひび・切れた電球／上がるたびに幕と棚が直り、3 で光の筋が回って金の線、4 で箔の色の光。
  - **視線**：買える品は立つ（色・黄の値札が糸で揺れる）。買えない品は沈む（色が抜ける・墨の値札）。足りないのに押すと、品と財布が震えて赤くなる。
  - 店に入ったときは幕が左右に引かれ、段ごとに品が降りる。
  - 1 段目（`data-tier="gimmick"`）：ギミック（糸で吊られた人形。品は `data-toy="<id>"`）。触ると見本（上の「ギミックとピエロの成長」）。
  - 2・3 段目（`data-tier="ext"`）：エクステンション（棚の品物。絵・★・値段・系統の色だけ。重ねられる品は右上に「重なった札 +点」（★が上がるときは次の★の色で「★n」、もうレジェンダリーなら「エンブレム +n」）、重ねる先の装備の枠の角に黄の ◆。要る仕掛けがない品は錠の印）。
  - 4 段目（`data-tier="gacha"`）：ヒーローのガチャのカプセルと、全部の段を入れかえるリロール（GUM。下の「ヒーローのガチャ」）。リロールでは、いまの品が袖へ引っこみ、反対の袖から新しい品が出て、止まるときに揺れて戻る（操り手のピエロが糸を引く）。
  - 舞台の下（客席側の帯）：装備の枠（★のゲージ）・ヒーローの枠（先頭がリーダー）・控え室・マレットのレベル・枠を広げる。
  - **説明の文は基本出さない**（ユーザーの指定）：スマホは 1 回目のタップで選んで吹き出し（名前・★・要点・値段）、同じものをもう 1 回で実行（吹き出しには、することの名前だけの黄の札：買う・重ねる・入れかえ・回す・広げる・鍛える・見る）。くわしい文は吹き出しの ? と段ごとの ? だけ。PC はマウスを重ねると吹き出し、1 クリックで実行。
  - 買った品は装備の枠へ飛び、着くと枠が弾んでスートの紙吹雪。売れた所に SOLD の判。財布の数字は変わった桁だけ転がる。重ねてレアリティが上がると進化の演出。ヒーローの枠はトランプの札（先頭は王冠）。枠がいっぱいで重ねられない品を買うときは、入れかえる装備を下から選ぶ（装備の枠に売値 +n）。装備の枠を触ると吹き出しに ◀ ▶（並べかえ）と「売る」（もう 1 回で確定）。

## ヒーローのガチャ（計算は `src/game/gacha.ts`・演出は `src/ui/gacha.ts`）
- ヒーローはショップの 4 段目のカプセルで、エンブレムを払って手に入れる（エンドレスのピラミッドのボスも落とす）。**ガチャで出たヒーローは挑戦の間だけ**：GAME OVER・通常のエンディングで、はじめのヒーロー（`save.starter`）だけに戻る（図鑑 `save.heroDex` には残る）。
- ★のカプセル：★1〜★5 が決まっている（値段 `CAPSULE_RAR_PRICE` 3・7・12・22・50＝エクステンションと同じ）。系統のカプセル（体力・知力・素早さ＝能力の系統）：★はランダム（重み `FAM_WEIGHTS`。その系統で持っていない★だけで割りなおす。値段 `CAPSULE_FAM_PRICE` 7）。控えの球 1 つで GUM がおよそ 3〜5 割増え（マレット 1 段ぶんくらい）、ラストステージは球の数でほぼ決まるので、ヒーローの枠（5）と合わせてマレットと張り合える値段にした（数値の合わせで、前の 5・10・18・32・64・系統 10・枠 8 から下げた）。並ぶのは★のカプセル 2 つ（★が違う。`RAR_OFFER_WEIGHTS`）＋系統のカプセル 1〜2 つ。出せるヒーローがいないカプセルは並べない。持っているヒーローは出ない。値引き（値切りの巻物）も効く（最低 1）。
- 出たヒーローは `save.heroes`・`save.heroDex` に入り、ヒーローの枠に空きがあれば編成（`save.party`）の後ろへ。いっぱいなら控え室（手元の人のボタンで編成に出し入れ）。カプセルは品ぞろえと一緒に引き直す（`save.capsules`。買ったら `sold`）。
- 演出（`src/ui/gacha.ts`・`gacha.css`）：切り絵の玉のカプセルが落ちて揺れ、ひびが入って開く。★1・2 は光がうすい／★3 は歓声／エピックは金のカプセル・「EPIC!!」の帯・ピエロがのぞく／レジェンダリーは画面がゆれ、幕が閉じて開くと箔のカプセル・「LEGENDARY!!」（その間はボスの曲）。結果はトランプの札（NEW の判・★・名前・系統と能力の名前の札）。行き先は絵と短い札：編成に入ったら枠の並び＋「IN!」、いっぱいなら「控え室」。

## オファーとボス台の掟（`src/game/offers.ts`・画面は `src/ui/offer.ts`）
- **オファー**：ミステリーのホールに入ると 30% で、実況が取引を持ちかける（1 プレイ 2 回まで）。いいことと悪いことがセットで、受けるか断るかを選ぶ（その間は時間が止まる）。受けた取引はそのプレイの間ずっと効く。画面は 2 つに切れるチケット（上の半券＝いいこと「＋」、下＝そのかわり「−」。見出しと説明の文は置かず、説明は OFFER の横の「?」）。受ける＝DEAL の判、断る＝破れて落ちる。
  | いいこと | そのかわり |
  | --- | --- |
  | このプレイの GUM ×2 | キックバックがなくなる |
  | バンパーの GUM ×3 | 赤（傾き）以外でバンパーに当てても GUM が出ない |
  | 次にノルマを納めたとき、Limited をもう 1 つ選べる | のこり時間 −5 秒 |
  | いますぐマルチボール | ボールセーブがきかない |
  | のこり時間 +8 秒 | いちばん左のエクステンションが、このプレイの間だけ外れる |
  | 的への攻撃 +50%・エクステンションの効果 ×1.3（上乗せ分） | 坂が 15% 重くなる |
  攻撃の色の決まり（弱点以外は等倍・半減しない）は崩さない。GUM の伸びはエクステンションが担うので、取引もエクステンションとヒートの印に効く中身にした。
- **ボス台の掟**：レイドボスの台（10・20・30・40・50）に入ると台が 1 つ意地悪に変わる（下のフリッパーが短い・坂が急・通り道のライトが消える・傾けると反対へ曲がる）。液晶には掟の名前だけが出る。突破すると、次にノルマを納めたときの Limited の候補 +1。

## ヒーローの能力（`src/game/abilities.ts`）
どのヒーロー（球）にも能力が 1 つ。いちばん高い能力値（体力・知力・素早さ）で系統が決まり、その中のどれかを ID で固定して当てる。強さはレアリティで ★1＝1 〜 ★5＝2.2。リーダー（自分の球）の能力はいつも効き、強さ ×1.5。控えの能力は、そのヒーローの球（控えの球・マルチボールの仲間の球・本物の球を引きついだ球）が台に出ている間だけ効く（分身はリーダーの能力）。守りの球（ボールセーブ +秒）は、打ち出したときに台に出ている球と、続けて打ち出される控えの分を足す（控えに付いていても効く。Limited で控えの能力が効かないときは除く。`PinballWorld.shieldK`）。
| 系統 | 能力 |
| --- | --- |
| 体力 | 重い球（坂で少し重く、攻撃 +）・雷の球（バンパーでまわりに電撃）・大当たり狙い（ランプのあと 3 秒だけ攻撃が大きく、ほかは −15%）・分裂（バンパー 10 回で分身）・跳ね返り（1 プレイに 1 回、落ちかけたら戻る）・守りの球（ボールセーブ +秒） |
| 知力 | 塗り（当てた的をいまの色の弱点に）・色で還元（弱点で倒すと GUM）・再充填（緑で倒すとキックバックが点き直し、ボールセーブがのびる）・まね（編成のとなりの能力）・貯金箱（持っている GUM の桁ごとに GUM +）・大当たりの目（ジャックポット・ランプ・ループの GUM +） |
| 素早さ | 軽い球（坂が軽い）・風の球（ブースターとループでさらに加速し、2 秒間攻撃 +）・ゆるい誘導（近くの的へ曲がる）・入口好き（ブラックホールと入口に吸われやすい）・倍率の供給（台に出ているだけで GUM +） |
- ショップのヒーローの枠を触る（PC はマウスを乗せる）と、吹き出しにそのヒーローの能力が出る。能力に要る部品（`ABILITY_TOYS`・`abilityReady`）が台になければ働かないだけで、こわれない。

## 解説モード（台のしくみ。`src/ui/guide.ts`・部品のデータは `src/game/parts.ts`）
ピンボールの部品の名前に詳しくない人のために、どこがどういう名前で、何が起きて、どんな改造を付けられるかを見せる（ユーザーの指定）。
- 入口：ラボの「台のしくみ」と、設定の「台のしくみを見る」。
- 台全体を映し、台にある部品（持っているギミックだけ。何もない台では打ち出しとフリッパーの 2 つ）に番号の名札を立てる。PC は名前の札にマウスを 0.16 秒乗せると、その部品へ寄って説明。名札か下の名前の一覧を触ると、カメラがその部品へ寄り（光る輪で囲み、まわりを暗くする）、球がその部品を通る実演が 3.6 秒ごとにくり返し流れる。
- 下は破れた半券 1 枚（`guide.css`）：番号の札の列・まえへ／つぎへ（矢のアイコン）・名前・1 行（説明のはじめの文）・いまの台の数字の札（スキルで変わるもの）・改造の数（スパナ＋数）。くわしい文・ピンボールでの呼び方・付けられる改造の名前（その部品に効くエクステンションの効果と Limited。持っていない Limited は数だけ）は名前の横の「?」。右上の数の札（n/全部）を触ると全体へ戻る。全体のときは文を置かず、番号の札が順に弾む。台の上の番号の札は墨の丸に骨の縁、選んだ札は黄。
- 実演は本物の台の計算を、セーブの写しと何もしない知らせで動かす（GUM・セーブ・実況・ピラミッドへの切りかえは起きない）。`tests/parts.test.ts` が、どの実演の球もその部品のそばを通るかを見る。
- はじめて球が触れた部品には、名前だけの札が 1 回だけ出る（`save.seenParts`。設定「はじめての部品に名前を出す」で消せる）。

## 画面（UI）の様式「呪われたカーニバル」（`src/styles/kit.css`・`frame.css`・`src/ui/kit/`。見本は `?kit=1`）
古いゲームコーナーの奥の、サーカスと人形劇の匂いがするピンボール。**切り絵のポスターとチケットとトランプ**でできた UI。ユーザーの方針「止めない・触れる質感・重ねる・500〜700ms の切りかえ・UI がいちばん鮮やか」と「説明テキストを極力なくす」を、この様式で形にする。評価の軸は直感性・視覚的階層・一貫性・フィードバック・アクセシビリティ。
**新しい画面・部品は、必ず kit の変数（`--k-*`）と部品（`.k-*`・`src/ui/kit/` の関数）で作る**。足りない部品は kit に足す。
- **色**（UI 用。攻撃の赤・青・緑 `--k-red`・`--k-blue`・`--k-green` は台の中の意味の色で、UI の地には使わない）：墨 `#0b0a10`（`--k-ink`。地）・骨 `#f4efe4`（`--k-bone`。字と紙）・血 `#e5163a`（`--k-blood`。差し色・危険）・チケット黄 `#ffd21f`（`--k-ticket`。GUM・決定）・呪いの紫 `#7b2cff`（`--k-curse`。Limited・呪い・影）・エンブレムの青緑 `#22e5c0`（`--k-emb`）。
  - 1 画面で主役の色は 1 つ。**黄は、その画面で「次に押す所／いちばん大事な数字」にだけ**使う（主ボタン `.k-btn--go` は画面に 1 つ）。
  - UI（ボタン・数字）がいちばん鮮やかで明るく、演出がその次、背景がいちばん暗い。
- **形**：角丸の箱は使わない。−6〜−10° に傾いた平行四辺形（`--k-skew`・`--k-tilt`）・破れたチケットの縁（clip-path）・切り絵の星形・網点（`--k-dots`）・テントの縞（`--k-tent`）・トランプのスート。太い墨の縁どり（`--k-line`）＋ずらした硬い影（`--k-shadow`。ぼかさない）。
- **字**：見出しは Dela Gothic One（和文。`--k-display`）と Bangers（欧文。`--k-en`）、本文は DotGothic16（`--k-body`）。数字は大きく・傾け・縁どり。大きさは変数 `--k-t-xs`(11)・`-s`(12)・`-m`(14)・`-l`(17)・`-xl`(22)・`-2xl`(34)・`-3xl`(56) で書く（px を直に書かない。設定「大きな字」で 1.15 倍）。本文は 12px 未満にしない（札の中の補助の数字だけ 11px まで）。
- **動き**（時間は `--k-fast` 120ms・`--k-mid` 280ms・`--k-scene` 600ms・ずらし `--k-stagger` 36ms）：
  - 出るとき：切りこむ（スライド＋傾き、行きすぎて戻る。`.k-in`。並ぶものは `style="--i:n"` でずらす）。
  - 場面の切りかえ（`motion.ts` の `wipe(kind, mid?, opts)`）：`'bars'` 斜めの帯（墨・血・黄。650ms）・`'page'` 紙めくり（700ms）・`'curtain'` 幕（900ms）・`'clap'` 墨の三角がかみ合う（1450ms）。覆われた瞬間に中身を入れかえる。直線の等速の動きは使わない。
  - 見せ場（`beat(name, opts)`）：`'launch'`（打ち出し。台を覆わない）・`'timeup'`・`'deposit'`（PAID の判）・`'gameover'`（幕）・`'evolve'`（光の帯）。
  - 待っている間も呼吸する（電球がまたたく・札がわずかに揺れる・網点が流れる）。止まった画面を作らない。無限に動く飾りは `animation-play-state: var(--k-play)`（`html.calm` と画質「低」で止まる）。
  - 数字は転がって増える（`rollNumber`・`rollText`）。押した所は星形に沈み、離すと跳ねる（`initKit` が document 全体で付ける）。成功は弾ける（`pop`・`burst`＝スートの紙吹雪）、失敗は震える（`shake`）。
- **文を置かない**（ユーザーの指定）：ラベルは 2 語まで、あとは数字・絵・形・動き。説明は「?」（`.k-help`。スマホはタップ、PC はマウスオーバー）と `data-tip` の中だけ。ピエロのセリフは世界観なので残す（短く）。
- **部品**（`parts.ts` の関数）：ボタン `.k-btn`（`--go` 主・`--sub`・`--danger`・`--curse`・`--icon` 44px・`--wide`・`--big`。`btn()`）・数の印 `.k-badge`・数字 `.k-num`・ゲージ `.k-gauge`・札 `.k-tag`・見出しの帯 `.k-ribbon`・切り絵のパネル `.k-panel`・チケットの札 `.k-ticket`・「?」`.k-help`・スート `.k-suit`・電球の列 `.k-bulbs`・攻撃の形 `.k-atk`・スイッチの札 `.k-switch`・3 択 `.k-seg`・モーダル `openModal`・トースト `toast`（左下の半券）・バナー `banner`（斜めの帯）。色は `data-tone="blood|ticket|curse|emb|bone|ink"`。
- **アクセシビリティ**：攻撃の 3 色は形でも分ける（赤＝●3 つ・青＝◇の輪・緑＝▲の矢。`.k-atk`）。設定「ひかえめ」（`html.calm`）・「大きな字」（`html.big`）・画質（上の「画質と演出の設定」）。ボタンは 44px 以上。
- **台が直るほど、UI も音も直っていく**（目玉の仕組み）：台に宿るピエロの段階（`clownOf(save)` 0〜4：ピエロ → エリート → ウィズダム → アルルカン → ジョーカー）を `<html data-clown="0..4">` に付ける（`main.ts` の `syncClown(wake)` → kit の `setClown`。変わると document に `kit:clown`、上がった瞬間は `k-waking` で電球が左から灯る）。
  - 0＝色あせ（色の変数が色あせる。色あせさせない所は `--k-*-0`）・電球が半分切れてちらつく・ひび・ほこり／1・2＝だんだん戻る／3＝全部点いて光が走る・金の縁・スートが出る／4（ジョーカー）＝満開。
  - 同じ属性を、盤面の絵（`src/fx/`）・ショップの舞台・スキルツリーの電球・BGM の楽器（下の「音」）も読む。
  - **上がる条件や数は書かない**（ユーザーの指定）。見た目と音が変わることで分かるようにする。段階 0 でも「次に押す所」の黄は読める濃さに残す。
- CSS の置き場所：`main.css`（前からの規則）→ `kit.css` → `frame.css`（上下の帯・フッター・シート・ラボ・PC の列）→ `g3.css`（吹き出し・オファー・遊び方・実況のことば）→ `show.css`（RESULT・発表・入金口・GAME OVER・場面）。画面ごとに `src/ui/` の `shop.css`・`tree.css`・`guide.css`・`coach.css`・`limited.css`・`gacha.css`・`reward.css`。

## 音（`src/audio/`。入口は `src/core/audio.ts`）

**BGM はマイクリのオリジナルの曲**（ユーザーの指定：アップテンポな曲）。場面ごとの割り当ては `src/audio/tracks.ts`：打ち出し待ち＝pve、プレイ＝land-battle、ボス＝raid、ショップ＝colosseum、ラボ＝9on9、RESULT＝pve-event、GAME OVER＝cryptid-wars、エンディング＝pvp。下の「その場で演奏する曲」は、曲が使えないときの代わりと合いの手に使う。効果音は合成のまま。
**音は全部 WebAudio の合成**（素材の BGM・SE は使わない。音のファイルを増やさない）。実況の声（`src/core/voice.ts`・`public/voice-en.bin`）だけはファイルのまま。様式は呪われたカーニバル（カリオペとオルガン・ファンクのベース・ブレイクビーツ・ブラス・ベル）。
- 構成：`theory.ts`（音の高さ・コード・音階・拍）・`dsp.ts`（ドラムと効果音のからだをその場で計算）・`engine.ts`（BGM・SE・声のバス → コンプレッサー → リミッター。リバーブとディレイ。同時に鳴る数は 22 まで `MAX_SOUNDS`）・`songs.ts`（楽譜 8 曲：idle 打ち出し待ち・play・boss ボス／ラストステージ・shop・lab・result・gameover・ending。同じ動機を全曲で使う）・`music.ts`（先読みのスケジューラ `Conductor` と `music`）・`sfx.ts`（効果音。名前は `SFX_NAMES`）・`ui.ts`（document 全体のボタンの音）。`tests/audio.test.ts`。
- **台が直るほど音も直る**（`<html data-clown>`）：段階 0 は単音の細いオルガン＋木魚＋レコードのぷちぷち＋テープのゆれ。上がるたびに ベース・ドラム → オルガンの和音・スネア → ブラス・タンバリン → ベルのアルペジオ・リード・クラップ（ジョーカー＝フルバンド）。
- **遊びに反応する**：連鎖 ÷ 20 が盛り上がり（20 連鎖から最高潮）。マルチボールと ZONE で転調（効果音の調も一緒に動く）。残り 10 秒でテンポを上げる。TIME UP で止めの一発 → 1.5 秒黙る → RESULT の曲。DRAIN で BGM がこもる。大当たりでブラスの合いの手。曲は拍の頭で切りかわる。曲は main.ts が `music.direct({ playing, boss, result, over, tab, combo, … })` で画面の様子から決める（特別な場面は `music.override(name)`。エンディングとレジェンダリーのガチャが使う）。
- **効果音**：`sfx(name, { x, power, step, p, vol })`。続けて当たるほど 5 音の音階を上る・左右のパン（台の x）・大事な一発は次の 16 分に寄せて BGM を短く下げる。DOM の約束：`data-sfx="名前"`（click でその音。`data-sfx-step`。`none` は無音＝自分で鳴らす要素）、付いていないボタン類は押しこみの `tap`（無効なら `deny`、PC のマウスが乗ると `hover`）、`data-sfx-in="名前"`（DOM に足された瞬間）。
- **音が抜けないように**：先読みは 30ms ごとに 0.2 秒先まで。メインスレッドが詰まった長さを覚えて 0.45 秒まで伸ばし（`Lookahead`）、開いた直後と TIME UP のあとは 0.7 秒（`music.brace(sec)` でも頼める）。わずかな遅れ（`LATE_OK` 45ms まで）は飛ばさずにすぐ鳴らす。
- 設定：音（ミュート）・実況の声・BGM と効果音の音量（`save.settings.bgmVol`・`seVol`。`setVolumes`）。
- 確認用：`__smash.audio`（`music`・`sfx`・`renderScene(name, 秒, 段階, 盛り上がり)`・`renderSfx(name, opts)`・`names`）。実機（スマホ）で耳では確かめられていない（音量のつり合いは実機で直す前提）。


## スキルツリー（`src/game/skills.ts`・画面は `src/ui/tree.ts`）
ラボの「スキルツリー」（プレイ中は下の帯のスキルツリー）で開く。開いている間はゲームが止まる。中心（いまのヒーロー）から 4 方向に、色と系統の枝が伸びる。
- **絵**（`tree.ts`・`tree.css`）：上から見たサーカスのテント。まん中の柱（ヒーローと回る光の輪）から 4 方向へ電球の線、スキルは切り絵。枝は形でも分ける（赤＝●・青＝◇・緑＝▲・黄＝★）。
  - 電球：持っている道＝灯る／取れる道＝スキルへ向かって光が流れる／先の道＝暗い（段階 0・1 は切れた電球が混じる）。
  - 切り絵：持っている＝枝の色の紙／取れる（エンブレムが足りる）＝骨の紙が呼吸し、黄の輪が広がり、右上に値札／足りない＝墨に枝の色の縁／先＝点線で沈む（名前は吹き出しで出る）／最大＝金の縁と MAX／到達点＝大きめ・二重の縁。
- **触り方**：下の説明の枠はない。切り絵のそばの吹き出し（`.sk-pop`：名前・Lv いま → 次・効き目の数字 いま → 次・値札のボタン。「?」で説明の文）。
  - スマホ：1 回目のタップで吹き出し、同じスキルをもう 1 回（か値札のボタン）で取る。取ったあとも選んだままなので、続けてタップすると続けて上がる。
  - PC：マウスを乗せると吹き出し（説明の文つき）、1 クリックで取る（先のスキルは手前からまとめて 1 クリック）。
  - 足りないときは切り絵と値札が震える。
  - 上の帯：戻る・4 つの枝のタブ（形＋取った数。触るとその枝へ寄る）・おまかせ・エンブレムの数。左下に「×1・×10・MAX」（何段も上がるスキルをまとめて上げる数）。

- 「おまかせ」（杖のアイコン。下に「よく使う」「バランス」の札：配り方の帯・+段数・エンブレム）：持っているエンブレムをぜんぶ使って、手前から順に自動で上げる。「よく使う」（おすすめ。色ごとに当てた回数 `save.usage` の割合で赤・青・緑に 3/4、黄に 1/4）か「バランス」（4 色に 1/4 ずつ）。割合が足りていない枝の、いちばん安い取れるスキルから上げていく（`skills.ts` の `autoPlan`）。全体で 3 秒ほどの速さで順に開く。

- 種類：何段も上げられる・1 回きり・到達点（`data-kind`）。
- 値段は `skillCost`、効き目の計算は `economy.ts` の `stats`。数値を変えるときはこの 2 つを触る。
- 攻撃力は「基本（ヒーローの PHY・図鑑）× 色ごとの威力」。玉突きと衝撃波は 3 色の威力の平均。
- 赤の吸い寄せ：傾けた向きから 40 度以内・260 ユニット以内でいちばん近い敵へ、加速の向きを少し曲げる（はじめから 28%、1 段ごとに +10%）。
- 前の版の強化（9 種）は、読み込んだときに対応する段へ読みかえる（`migrateLevels`）。

## デバッグ用の URL・セーブの項目
- URL（どこからもリンクしない）：`?reset=1`（セーブを消す）、`&name=ベアコ`（名前を決めて導入をとばす。ホームは出る）、`&go=1`（ホーム画面をとばす）、`&gum=100000`、`&table=8`（ピンボールをその台から）、`&floor=20`（ピラミッドの階。エンドレスのとき）、`?pc=1`・`?pc=0`（PC の 3 画面を出す・出さない）、`?kit=1`（UI の部品の見本。段階 0〜4・ひかえめ・大きな字を切りかえられる）、`?post=0`・`?post=1`（WebGL の後がけを使わない・ソフトウェア描画でも使う）。
- コンソールの `__smash`：world（いまのモード）・pyramid・pinball・sensors・save・audio。`__fx()`（画質の段階・後がけ・描く時間）・`__fxq(0|1|2)`（画質を決めて自動を止める）・`__fxInstall(id)`（部品の取り付けの演出）・`__fxcam = {x, y, vw}`（カメラを決める）・`__pinprof = {}`（描く区切りごとの ms がたまる）。打ち出したプレイを早く終えるときは `__smash.pinball.runLeft = 0.3`。
- セーブ（`src/core/save.ts`）の主な項目：`save.quota`（いまの挑戦：`n`（0 はチュートリアル）・`played`・`guide`（案内つきのチュートリアル）・`tutJust`（案内つきのチュートリアルを納めた直後）・`mallet`・`final` など）・`save.tutorialDone`（チュートリアルを一度納めた）・`save.partsV`（部品を買い足すしくみに移った印。前の版のセーブは `migrateParts` が 1 回だけ引きつぐ）・`save.toys`（買ったギミック）・`save.toyShop`（ギミックの候補）・`save.shop`（エクステンションの品ぞろえ）・`save.capsules`（ガチャのカプセル）・`save.starter`（はじめのヒーロー）・`save.heroes`・`save.party`・`save.heroDex`（図鑑）・`save.emblems`・`save.stack`（重ねの点）・`save.runs`（打ち出したプレイの数）・`save.endless`・`save.settings`（`mute`・`voice`・`vibrate`・`bgmVol`・`seVol`・`calm`・`bigText`・`quality` など）。画質の自動の結果はセーブとは別に `localStorage` の `mycryptosmash.fxq.v1`。

## 共通基盤（bearko.games）

## 素材
`vendor/mycryptoheroes`（サブモジュール）から `scripts/sync-assets.mjs` が使うものだけを `public/mch/` に写す。
- 背景：縦長のバトル背景をステージごとに順番に
- エネミー：色ちがい 6 段階の群れを 10 種。周回するほど上の段の色が出る。ボスは 4 種
- エクステンション：ピラミッドで拾ったときの効き目（12 秒の強化・衝撃波）をシリーズごとに決める（`scripts/sync-assets.mjs` の `KIND_SERIES`）。ショップでのスコアの効果は `src/game/exts.ts`
- 効果音・BGM：素材のものは使わない（`sync-assets.mjs` は写さない）。全部 WebAudio の合成（上の「音」）
