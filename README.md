# My Crypto Smash

スマホを **引っぱって・傾けて・振って** 遊ぶ、ピンボール＋育成のブラウザゲームです。
呪われたピンボールで GUM を稼ぎ、台を部品から育てて、ノルマのインフレに打ち勝ちます。
My Crypto Heroes の非公式二次創作（無料・非営利）です。

## 遊び方

古いゲームコーナーに閉じこめられた主人公が、呪われたピンボールで GUM を稼ぎ、「入金口」にノルマを納めて脱出をめざします。

- **引っぱって離す**：打ち出しの通路から球を打ち出す（押している間は傾き・振りを使わない）
- **傾ける**：打ち出した球を少し曲げる
- **振る**：台を揺らす
- **水平リセット**（左下）：いま持っている角度を「水平」にする
- PC：W・A・S・D（矢印）で傾き、スペースで振り、マウスで引っぱって離す

「はじめる」ボタンはなく、球を打ち出した瞬間にプレイが始まります。1 回のプレイは 40 秒のピンボール（フリッパーは自動）。プレイのあとに、稼いだ GUM を「基本額 × 倍率」で発表します。ノルマは 10 段階で、納品額は 200 GUM から毎回 4 倍。各ノルマは 3 プレイ以内に納めないと GAME OVER です。
はじめの台は打ち出しとフリッパーだけ。プレイと納品で手に入るエンブレムで、台の部品と仕掛け（ギミック）・ヒーローのガチャ・エクステンション（スコアの効果。同じシリーズを重ねてレアリティを上げる）・マレットのレベル（基礎ポイント）・スキルツリーを買い、ノルマを納めるたびに Limited を 1 つ選びます。
ノルマ 10 を納めれば部屋から出られます（通常のエンディング。スキルツリーを持って最初から）。仕掛けを買い足して台に宿るピエロをジョーカーに戻してからノルマ 10 を納めるとラストステージ（ボスラッシュ）。突破すれば真のエンディングです。

センサーは HTTPS のページでしか使えません。iOS では、はじめて打ち出そうとしたときに出る許可を「許可」にして、もう一度引っぱってください。

## 特徴

- **様式「呪われたカーニバル」**：切り絵のポスター・チケット・トランプでできた UI。説明の文は置かず、数字・形・動きで伝えます（くわしくは「?」の中だけ）。
- **台が直るほど、UI も音も直る**：ギミックを買い足して台に宿るピエロが育つと、色あせた画面に色と電球が戻り、音楽の楽器が増えていきます。
- **音は全部その場で合成**（WebAudio）：連鎖・マルチボール・残り時間に合わせて曲が盛り上がり、転調します。実況の声つき。
- **台の演出**：木とサーカスの盤面、火花と粒子、WebGL の後がけ（ブルーム・衝撃波）。重い端末では画質を自動で下げます（設定で 高・中・低）。
- **アクセシビリティ**：攻撃の 3 色は形でも区別（●・◇・▲）。設定に「ひかえめ」（点滅とゆれを弱める）と「大きな字」。

## 開発

```sh
git clone --recurse-submodules https://github.com/bearko/MyCryptoSmash
npm install
npm run dev      # 同じ Wi-Fi のスマホからも開ける（センサーは HTTPS が必要なので、スマホでの確認は公開先で）
npm test
npm run build
```

素材は [bearko/mycryptoheroes](https://github.com/bearko/mycryptoheroes) をサブモジュール（`vendor/mycryptoheroes`）として読み込み、
`scripts/sync-assets.mjs` が使うものだけを `public/mch/` に写します。

## 公開（Cloudflare）

Cloudflare Workers の静的配信です（`wrangler.jsonc`、`dist/` を配信）。
Workers Builds でこのリポジトリをつなぎ、ビルドコマンド `npm run build`、デプロイコマンド `npx wrangler deploy` を設定します。
サブモジュールが取得されていない場合は、ビルドの最初（`scripts/sync-assets.mjs`）で取得します。
